🔗 Bulk URL Extractor
Paste a NovelBin or NovelArrow novel page (e.g. novelbin.com/b/novel-slug or novelarrow.com/novel/novel-slug) and this tool will fetch & list all chapter URLs automatically. For NovelArrow, chapters are fetched directly from the JSON API — only free chapters (no premium/coin-locked) are shown. Select the ones you want, then send them straight to the Bulk Scraper.
📋 PASTE FALLBACK
Auto-fetch blocked? Do this instead:
1. Open the novel page in a new tab
2. Press Ctrl+U (or right-click → View Page Source)
3. Press Ctrl+A then Ctrl+C to copy all
4. Paste it below and click Extract
For novelarrow.com novels, fetch the chapter list JSON directly:
1. Open this URL in a new tab (replace <slug> with your novel's slug):
  https://novelarrow.com/api-web/novels/<slug>/chapters?sort=asc
2. Press Ctrl+A then Ctrl+C to copy all the JSON
3. Paste it below and click Extract
